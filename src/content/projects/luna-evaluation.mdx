Evaluation architecture for AI-based rider assistance systems on motorcycles and bikes, measuring performance against the product's safety functions rather than raw model scores.

## More info

Designed and built the framework to store model outputs, so metrics can be recomputed as definitions evolve.
Grounded each safety function in empirical definitions of success and measurable KPIs, carried through into the customer-facing technical specifications.
**Moved R&D toward metrics-driven development.**
