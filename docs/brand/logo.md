# Logo

The site mark is a **damped sine wave** — a single thick stroke in the brand
purple on the dark background. It replaced an earlier "yg" initials monogram.
It shares its DNA with the momentum curve used elsewhere in the brand, distilled
to one quiet line.

## Colors

| Token | Value | Notes |
|-------|-------|-------|
| Brand purple | `oklch(0.7188 0.1405 285.08)` → `#9C96F8` | site `--color-brand` (dark mode); hex is the sRGB fallback for tools without oklch |
| Background | `#282C34` | site `--color-bg-base` (dark) |

Chosen weight: `stroke-width: 10` (in the 400-unit viewBox), `stroke-opacity: 0.8`.
Dark tile only.

## Regenerating

The mark is generated deterministically — same bytes every run.

```bash
python3 scripts/generate-logo.py        # writes docs/brand/logo.svg (+ logo-transparent.svg)
bash   scripts/generate-favicons.sh     # rasterizes logo.svg into the public/ favicon set
```

`generate-logo.py` has no dependencies. `generate-favicons.sh` needs
ImageMagick (`magick`) plus a SVG rasterizer — `rsvg-convert` if installed,
otherwise headless Google Chrome / Chromium.

## Source of truth

- `docs/brand/logo.svg` — dark tile, resolution-independent
- `docs/brand/logo-transparent.svg` — wave only, for use on other backgrounds

`stroke-width` lives in the viewBox, so the line scales proportionally at any
export size.

## Where it's used

Rasterized into the favicon set under `public/` (regenerated by the script above):

- `favicon.ico` (16 + 32)
- `favicon-16x16.png`, `favicon-32x32.png`
- `apple-touch-icon.png` (180)
- `android-chrome-192x192.png`, `android-chrome-512x512.png`

Referenced from `src/layouts/BaseLayout.astro` (`<link rel="icon">` /
`apple-touch-icon` / manifest) and `public/site.webmanifest`. The paths are
stable — only the image bytes change on regeneration.

## Notes

- Full-bleed **square** dark tiles (platforms apply their own masking/rounding).
  The previous icons were a circle; to restore that, clip the SVG with a
  `<circle>` mask.
- Legible down to ~32px; at 16px it reads as an abstract squiggle (fine for a
  favicon).
- The same `logo.svg` (dark tile, 400×400 → export larger) is the LinkedIn
  company logo.
