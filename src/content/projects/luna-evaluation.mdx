Designed and built the evaluation stack for a camera-based rider assistance system on motorcycles and bikes, along with the function definitions it measures against.

## More info

Established event-level ground truth for warnings, and iteratively refined the metrics and test sets used to evaluate function performance.

Detection, tracking and warning outputs are stored per model version, so metrics can change without re-running inference. Every false alarm can be traced to the stage that caused it, which surfaced specific failure sources such as track loss spawning new IDs and warnings firing on a single frame.

Built the function portfolio, the product's customer offering, around the team's algorithmic capabilities and market requirements. Wrote the technical definition of each safety function: activation conditions, success metrics, configurable parameters.

**Gave the team its first measure of the warnings actually delivered to riders.** Model selection, warning logic and the R&D loop were rebuilt around these definitions, and the same metrics carried into customer specs. Warning performance improved as work shifted to optimizing against them.
